# 🎲 모두의 마블 은행

모두의 마블 **실물 보드게임**을 할 때 지폐 대신 각자 휴대폰·태블릿으로 돈을 주고받는 웹앱입니다.
보드·말·주사위·카드는 그대로 쓰고, **돈 계산만** 앱이 대신합니다.

- 한 명이 **방 만들기** → 4자리 방 번호가 나옵니다 (방장)
- 나머지는 방 번호를 입력하거나 공유된 링크로 **참가** (최대 4명)
- 누가 돈을 주고받으면 모든 기기에 **실시간으로** 잔액이 바뀌고, 받은 사람 폰에는 알림과 진동이 옵니다
- 앱을 닫았다 열어도 자동으로 같은 방에 다시 들어갑니다. 서버를 껐다 켜도 게임은 저장되어 있습니다

## 들어 있는 기능 (규칙 반영)

| 버튼 | 하는 일 |
| --- | --- |
| 🏁 월급 | 출발지를 지날 때 **+30만** (세계여행으로 지나갈 때도) |
| 🧾 통행료 | 땅 주인을 고르고 카드에 적힌 통행료를 입력. **컬러 독점 ×2**, **올림픽 배수**가 자동으로 곱해져 주인에게 감 |
| 🤝 인수 | 현재 건설가(땅+건물)를 입력하면 **2배**를 주인에게 지불. 랜드마크 도시는 인수 불가 |
| 🏠 구매·건설 | 땅 구매, 별장·빌딩·호텔·랜드마크 건설 → 은행에 지불 |
| 🏝️ 보석금 | 무인도 탈출 보석금 지불 |
| 🏦 은행에 내기 / 🎁 은행에서 받기 | 세금, 찬스카드, 올림픽 개최 등 |
| 💸 송금 | 다른 플레이어에게 직접 보내기 |
| 🏚️ 매각 | 돈이 모자랄 때 땅·건물을 은행에 팔기 |
| ☠️ 파산 | 남은 돈은 빚진 사람(또는 은행)에게 가고 부족한 금액은 내지 않음. 마지막 1명이 남으면 자동 승리 |

- 잔액보다 큰 돈을 내려고 하면 막고, **매각** 또는 **파산**을 고르게 합니다.
- 모든 거래는 기록에 남고 **취소**할 수 있습니다 (본인 거래는 본인이, 모든 거래는 방장이).
- 방장 메뉴: 잔액 직접 수정, 다른 플레이어 파산 처리, **승리 선언**(트리플 독점 / 라인 독점 / 관광지 독점).

### 기본 설정값과 바꾸는 법

| 항목 | 기본값 |
| --- | --- |
| 시작 자금 | 200만 마블 |
| 월급 | 30만 마블 |
| 무인도 보석금 | 20만 마블 |
| 컬러 독점 통행료 | ×2 |
| 올림픽 통행료 | ×2 (개최할 때마다 곱해짐) |
| 인수 가격 | 건설가 ×2 |
| 은행 매각 | 50% |

모두의 마블 보드게임은 베이직·이코노미·메가디럭스 등 판본이 여러 개라 금액이 조금씩 다를 수 있습니다.
가지고 있는 게임 설명서와 다르면 **방장이 대기실에서 "설정 바꾸기"** 로 고치면 됩니다.

## 실행하기

Node.js 18 이상만 있으면 됩니다 (설치할 라이브러리 없음).

### 방법 1. 집에서 컴퓨터 한 대로 (같은 와이파이)

```bash
npm start
```

실행하면 이렇게 주소가 나옵니다:

```
  이 컴퓨터:   http://localhost:3000
  같은 와이파이: http://192.168.0.12:3000
```

모든 휴대폰·태블릿을 **같은 와이파이**에 연결한 뒤 `같은 와이파이` 주소로 들어가면 됩니다.

### 방법 2. 인터넷에 올리기 (컴퓨터 없이 언제든)

[Render](https://render.com) 같은 무료 호스팅에 올리면 어디서든 접속할 수 있습니다.

1. Render 가입 → **New → Blueprint** → 이 GitHub 저장소 선택
2. `render.yaml` 설정대로 자동 배포됩니다
3. 나온 주소(`https://...onrender.com`)를 휴대폰으로 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다

> 무료 서버는 한동안 안 쓰면 잠들어서 처음 접속할 때 30초쯤 걸릴 수 있습니다.

## 개발

```bash
npm test     # 돈 계산 규칙 테스트
```

- `src/game.js` — 돈 계산 규칙 (월급, 통행료, 인수, 파산, 되돌리기 등)
- `server.js` — 방 만들기/참가, 실시간 동기화(Server-Sent Events), 파일 저장
- `public/` — 휴대폰 화면
