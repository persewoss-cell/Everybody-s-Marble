# 🎲 모두의 마블 보조앱

**모두의 마블 메가 디럭스** 실물 보드게임을 할 때, 지폐 대신 각자 휴대폰·태블릿으로 돈을 주고받는 웹앱입니다.
보드·말·주사위·카드는 그대로 쓰고, **돈 계산만** 앱이 합니다. 모든 규칙은 동봉된 룰북 기준입니다.

👉 **https://persewoss-cell.github.io/Everybody-s-Marble/**

## 사용법

1. 한 명이 **새 방 만들기** → 방장이 됩니다. 방장 기기가 은행 역할을 하니 게임하는 동안 화면을 켜 두세요.
2. 나머지는 **열려 있는 방** 목록이나 방 번호로 들어옵니다 (2~4명).
3. 방장이 **게임 시작** → 모두 200만 마블, 축제도시 3곳이 무작위로 정해집니다.
4. 말이 도착한 **칸을 누르면** 구매·건설·통행료·인수가 자동으로 계산됩니다.
5. 튕기면 **같은 이름 + 같은 방 번호**로 다시 들어오면 그대로 이어집니다.

- ⛶ 버튼: 전체화면 (아이폰은 공유 → "홈 화면에 추가"로 열면 주소창 없이 쓸 수 있어요)
- ↩ 되돌리기: 가장 최근 거래를 하나씩 되돌립니다 (본인 거래는 본인이, 방장은 모두)
- 버튼을 누르면 내 화면에는 바로 반영되고, 방장 기기가 확인해서 모두에게 맞춰 줍니다

### 👩‍🏫 선생님 관리 모드 (수업용)

선생님 컴퓨터에서 처음 화면 맨 아래 **선생님 관리 모드** → 방 개수(2~6개)와 방 종류를 고르고 **조별 방 만들기**.

- 선생님은 게임에 참여하지 않고, 이 컴퓨터가 모든 조 방의 은행 역할을 해요. **게임하는 동안 이 탭을 켜 두세요.**
- 학생들은 처음 화면의 열려 있는 방에서 **1조·2조…** 를 누르거나 방 번호로 들어와 말 색을 골라요.
- 관리 화면 위쪽에 조별 작은 상자가 한 줄로, 아래에 조별 게임판이 두 개씩 실시간으로 보여요 (말 위치·건물·남은 돈·차례). **대기 중인 방 모두 시작**으로 한꺼번에 시작해요.
- **열기**를 누르면 그 방 게임판을 보면서 되돌리기·잔액 수정·파산 처리·차례 넘기기·게임 종료를 할 수 있어요 (이 권한은 선생님만).
- 선생님 컴퓨터를 새로고침해도 방들이 그대로 이어져요.

### 방 종류 (방 만들 때 고름)

- **🎲 앱 + 실물**: 실물 보드·주사위로 하고 돈 계산은 앱으로. 순서는 자유롭게, 앱 주사위도 쓸 수 있어요.
- **📱 앱으로만**: 주사위·차례·포춘카드까지 앱이 관리해요.
  - 시작하면 모두 주사위를 굴려 높은 사람부터 순서를 정해요 (같으면 그 사람들만 다시).
  - 내 차례에 🎲 → 주사위가 3초간 돌다 멈추고, 말이 한 칸씩 이동 → 도착한 칸 화면이 자동으로 열려요. 출발지를 지나면 월급은 자동.
  - 더블이면 한 번 더, 세 번 연속 더블이면 무인도. 무인도는 3차례 쉬고 더블·보석금·탈출 카드로 나와요.
  - 세계여행 칸에 서면 다음 차례에 주사위 대신 10만 내고 원하는 도시로 가서 사거나 지어요 (안 가고 주사위를 굴려도 돼요). 더블로 도착했으면 지금 여행하거나 안 가고 한 번 더 굴려요 (여행하면 그 도시에서 한 번 더).
  - 출발지에 도착하면(주사위·세계여행·출발지로 GO 카드) 그 차례에 내 도시 한 곳에 건물을 지을 수 있어요.
  - 규칙대로만 진행돼요: 남의 땅에 서면 통행료를 내야(닫기·✕ 없음), 국세청이면 세금을 내야, 포춘카드 칸이면 랜덤으로 뽑아야 차례를 끝낼 수 있어요. 사고 짓는 건 말이 도착한 칸에서만, 포춘카드는 고를 수 없고 뽑은 카드만 써요.
  - **🤖 컴퓨터 추가**: 사람이 모자라면 대기실에서 방장(선생님)이 컴퓨터 플레이어를 넣을 수 있어요 (4명까지). 컴퓨터 차례는 방장 기기가 자동으로, 동작마다 잠깐씩 쉬면서 진행해요. 돈이 넉넉하면 땅을 사고 짓고, 통행료·세금이 모자라면 싼 도시부터 매각해요.
  - 말 옮기기·송금·되돌리기는 방장만 (방장 메뉴 → 말 옮기기로 잘못을 바로잡을 수 있어요).
  - 포춘카드는 27장 중 랜덤 뽑기. 보관 카드(천사·할인쿠폰·방패·무인도 탈출·월급 부스터)는 1장만, 공격을 받으면 방패(없으면 천사)로 자동 방어.
  - 보너스 게임은 앱에서 동전 앞뒤 맞히기로.
  - 주사위·카드 장면과 말 이동은 모든 기기에 함께 보여요.

## 들어 있는 규칙 (룰북 기준)

📖 룰북 PDF: https://persewoss-cell.github.io/Everybody-s-Marble/rulebook.pdf — 공식 룰북을 이 앱 규칙에 맞게 고친 것 (처음 화면·규칙 요약에서도 받을 수 있어요)


| 항목 | 내용 |
| --- | --- |
| 월급 | 출발지를 지날 때마다 30만 (월급 부스터 카드면 2배). 지날 때마다 다음 턴 |
| 건설 턴 제한 | 첫 턴 빌라까지 → 두 번째 빌딩까지 → 세 번째 호텔까지 → 그 뒤 자유. 랜드마크는 빌라·빌딩·호텔이 다 있는 내 도시에 도착했을 때 |
| 통행료 | 건설된 건물 통행료의 합 × 컬러독점 2배 × 축제 2배 × 올림픽 2~5배 (전염병·황사 50%, 정전 무료, 할인쿠폰 50%, 천사 면제) |
| 관광지 | 구매 10만. 섬은 가진 섬 개수, 해변은 방문 횟수로 깃발 8만 → 파라솔 16만 → 방갈로 32만. 매각 5만, 인수 불가 |
| 인수 | 통행료를 낸 뒤 인수비용(건설비용 2배). 관광지·랜드마크 도시 불가 |
| 매각 | 매각 버튼으로 원할 때 (앱으로만 하는 방은 내 차례에), 통행료·세금이 부족하면 매각 화면이 자동으로. 매각비용은 건설비용 절반 |
| 특수칸 | 국세청 20만, 무인도 보석금 20만, 올림픽 개최 10만(한 곳에만, 최대 ×5), 세계여행 10만(원하는 도시로), 보너스 게임 40/80/160만 |
| 포춘카드 | 21종 — 후원금, 도시체인지(맞교환), 도시기부(랜드마크 도시 제외), 강제매각, 지진, 외계인 침공, 전염병, 황사, 도시정전 등 |
| 승리 | 트리플·라인·관광지 독점 자동 판정, 나머지 모두 파산, 시간 종료 시 총자산(마블 + 땅·건물·랜드마크 건설비용) 1등 |
| 게임 시간 | 방장(선생님)이 ⏰ 타이머로 정함. 시간이 다 되면 자동으로 끝나고, 언제든 바로 끝낼 수도 있음 |
| 파산 | 땅·건물은 모두 치우고 보관 카드도 버림, 남은 마블은 빚진 사람에게 |

## 구조

GitHub Pages는 파일만 올려 두는 곳이라 서버가 없습니다. 방장 기기가 은행으로서 규칙을 계산하고,
기기들끼리는 무료 공개 메시지 중계 서버(MQTT 브로커: `broker.emqx.io`, 안 되면 `broker.hivemq.com`, `test.mosquitto.org`)로 주고받습니다.
방 번호를 아는 사람은 잔액을 볼 수 있습니다.

- `game.js` — 룰북 규칙과 도시증서 23장 가격 (방장 기기에서 실행, 다른 기기는 미리 계산용)
- `bot.js` — 컴퓨터 플레이어가 할 일 고르기 (방장 기기에서 실행)
- `net.js` — 방 만들기·참가·재입장, 실시간 통신
- `app.js`, `index.html`, `style.css` — 화면
- `vendor/mqtt.min.js` — [MQTT.js](https://github.com/mqttjs/MQTT.js) 5.10.4 (MIT)

`main` 브랜치에 올리면 GitHub Pages가 자동으로 다시 배포합니다.

```bash
npm test   # 규칙 테스트 (룰북 예시 금액으로 확인)
```
