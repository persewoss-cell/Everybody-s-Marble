# 🎲 모두의 마블 은행

모두의 마블 **실물 보드게임**을 할 때 지폐 대신 각자 휴대폰·태블릿으로 돈을 주고받는 웹앱입니다.
보드·말·주사위·카드는 그대로 쓰고, **돈 계산만** 앱이 대신합니다.

- 한 명이 **방 만들기** → 4자리 방 번호가 나옵니다 (방장)
- 나머지는 방 번호를 입력하거나 공유된 링크로 **참가** (최대 4명)
- 누가 돈을 주고받으면 모든 기기에 **실시간으로** 잔액이 바뀌고, 받은 사람 폰에는 알림과 진동이 옵니다
- 앱을 닫았다 열어도 자동으로 같은 방에 다시 들어갑니다. 게임은 방장 기기에 저장되어 있어서 방장이 다시 열면 그대로 이어집니다

## 들어 있는 기능 (규칙 반영)

| 버튼 | 하는 일 |
| --- | --- |
| 🏁 월급 | 출발지를 지날 때 **+30만** (세계여행으로 지나갈 때도) |
| 🧾 통행료 | 땅 주인을 고르고 카드에 적힌 통행료를 입력. **컬러 독점 ×2**, **올림픽 배수**가 자동으로 곱해져 주인에게 감 |
| 🤝 인수 | 현재 건설가(땅+건물)를 입력하면 **2배**를 주인에게 지불. 랜드마크 도시는 인수 불가 |
| 🏠 구매·건설 | 땅 구매, 별장·빌딩·호텔·랜드마크 건설 → 은행에 지불 |
| 🏝️ 보석금 | 무인도 탈출 보석금 지불 |
| 🏦 은행에 내기 / 🎁 은행에서 받기 | 세금, 찬스카드, 올림픽 개최 등 |
| 💸 송금 | 다른 플레이어에게 직접 보내기 |
| 🏚️ 매각 | 돈이 모자랄 때 땅·건물을 은행에 팔기 |
| ☠️ 파산 | 남은 돈은 빚진 사람(또는 은행)에게 가고 부족한 금액은 내지 않음. 마지막 1명이 남으면 자동 승리 |

- 잔액보다 큰 돈을 내려고 하면 막고, **매각** 또는 **파산**을 고르게 합니다.
- 모든 거래는 기록에 남고 **취소**할 수 있습니다 (본인 거래는 본인이, 모든 거래는 방장이).
- 방장 메뉴: 잔액 직접 수정, 다른 플레이어 파산 처리, **승리 선언**(트리플 독점 / 라인 독점 / 관광지 독점).

### 기본 설정값과 바꾸는 법

| 항목 | 기본값 |
| --- | --- |
| 시작 자금 | 200만 마블 |
| 월급 | 30만 마블 |
| 무인도 보석금 | 20만 마블 |
| 컬러 독점 통행료 | ×2 |
| 올림픽 통행료 | ×2 (개최할 때마다 곱해짐) |
| 인수 가격 | 건설가 ×2 |
| 은행 매각 | 50% |

모두의 마블 보드게임은 베이직·이코노미·메가디럭스 등 판본이 여러 개라 금액이 조금씩 다를 수 있습니다.
가지고 있는 게임 설명서와 다르면 **방장이 대기실에서 "설정 바꾸기"** 로 고치면 됩니다.

## 어떻게 동작하나요?

- GitHub Pages는 파일만 올려 두는 곳이라 따로 서버가 없습니다.
- 그래서 **방장 휴대폰이 은행 역할**을 합니다. 모든 돈 계산과 기록은 방장 기기에서 처리하고 방장 기기에 저장됩니다.
- 기기들끼리는 무료 공개 메시지 중계 서버(MQTT 브로커: `broker.emqx.io`, 안 되면 `broker.hivemq.com`, `test.mosquitto.org`)를 통해 실시간으로 주고받습니다.
  와이파이든 LTE든 인터넷만 되면 됩니다.

### 꼭 알아 두세요

- **방장 휴대폰은 게임하는 동안 이 화면을 켜 두세요.** (앱이 화면 꺼짐을 막아 줍니다)
  방장 화면이 꺼져 있으면 다른 사람의 거래가 "방장 기기가 응답하지 않아요"라고 나오고 처리되지 않습니다. 방장이 다시 열면 그대로 이어집니다.
- 방장이 브라우저 기록을 지우거나 다른 기기로 바꾸면 그 방은 이어갈 수 없습니다.
  이럴 때는 화면에 남아 있는 잔액을 보고 새 방을 만든 뒤, 방장 메뉴의 **잔액 직접 수정**으로 맞추면 됩니다.
- 공개 중계 서버를 쓰므로 방 번호를 아는 사람은 잔액을 볼 수 있습니다. (돈 거래는 참가자만 할 수 있습니다)

## 수정해서 다시 올리기

`main` 브랜치에 올리면 GitHub Pages가 자동으로 다시 배포합니다. 빌드 과정은 없습니다.

```bash
npm test     # 돈 계산 규칙 테스트
```

- `game.js` — 돈 계산 규칙 (월급, 통행료, 인수, 파산, 되돌리기 등). 방장 기기에서 실행
- `net.js` — 방 만들기/참가, 방장 기기와 다른 기기 사이의 실시간 통신
- `app.js`, `index.html`, `style.css` — 휴대폰 화면
- `vendor/mqtt.min.js` — MQTT 라이브러리 ([MQTT.js](https://github.com/mqttjs/MQTT.js) 5.10.4, MIT)
